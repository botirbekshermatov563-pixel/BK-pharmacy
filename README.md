## ✨ Особенности и возможности

- **Уникальный медицинский дизайн**: мягкие оттенки изумрудно-зелёного (`#16a34a`, `#0d9488`), снежно-белого и мятного. Округлые карточки, мягкие тени (`box-shadow`), отсутствие визуального шума.
- **Двуязычный интерфейс (RU / UZ)**: мгновенный переключатель в шапке сайта. Полный перевод каталога, состава, показаний к применению, корзины и системных уведомлений.
- **Интерактивный блок подбора по потребностям**: 8 ключевых категорий здоровья (Сон и стресс, Иммунитет, Витамины, Суставы, Пищеварение, Женское здоровье, Детские товары, Вены и сосуды). При клике плавно скроллит к каталогу и активирует нужный фильтр.
- **Каталог 16+ оригинальных препаратов**: Коледан (капли/капсулы), Йодофол, Эмфетал, Полижен, Рейтоил, Вамелан (капсулы/сироп), Протекта (шипучие/Эдванс), Сановит, Артрокол, Венодиол-Ультра и др.
- **Живой поиск, фильтрация и сортировка**: мгновенный поиск по названию, действующему веществу и показаниям; сортировка по популярности, цене и названию; постраничная пагинация (по 8 товаров).
- **Карточка товара (Quick View Modal)**: быстрый просмотр с вкладками состава, показаний, способа применения, дозировки и выбора количества.
- **Корзина и оформление заказа**:
  - Выдвижная панель (Slide-over drawer) справа.
  - Индикатор бесплатной доставки при заказе от 150 000 сум.
  - Изменение количества, удаление, расчёт общей суммы.
  - **Прямая отправка заказа в Telegram директора** (`https://t.me/Botirbek_Baxtiyarovich`) со списком товаров, ценами и адресом доставки.
- **Защищённая панель администратора (`/admin`)**:
  - Авторизация через Supabase Auth (или локальный демо-доступ).
  - Управление товарами: добавление, редактирование (RU/UZ тексты, цены, состав, инструкция, рейтинг, наличие), удаление.
  - Загрузка картинок через Supabase Storage.
  - Управление категориями.
  - Управление заказами: просмотр поступивших заявок и смена статусов (*Новый*, *В обработке*, *Завершён*, *Отменён*).
  - CMS настроек сайта: редактирование контактов директора, телефонов, Telegram и слоганов баннеров прямо из интерфейса.

## 🛠 Технологический стек

- **Frontend**: React 18, Vite 6, Tailwind CSS, Lucide Icons.
- **Backend & Database**: Supabase (PostgreSQL, Supabase Auth, Supabase Storage).
- **Локализация**: Кастомный реактивный контекст `i18n` с поддержкой русского и узбекского (Latin).
- **Fallback Режим**: Полная работоспособность локально (LocalStorage DB) без обязательного первоначального подключения API-ключей.

## 🚀 Быстрый старт (Локальный запуск)

### Вариант 1: Запуск через Node.js (Рекомендуемый)

1. Убедитесь, что у вас установлен Node.js (версии 18+):
   ```bash
   node -v
   ```
2. Перейдите в папку проекта:
   ```bash
   cd bk-pharmacy
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
5. Откройте в браузере: `http://localhost:3000`

### Вариант 2: Мгновенный запуск без установки Node.js

В проекте подготовлен готовый файл **`preview.html`**, который содержит всю функциональность приложения (каталог, корзину, оформление заказа, переключение RU/UZ и админку).  
Просто откройте файл `preview.html` двойным кликом в любом браузере (Google Chrome, Microsoft Edge, Safari, Firefox).

## 🗄 Подключение Supabase

Для сохранения товаров, заказов и картинок в облачной базе данных Supabase:

### Шаг 1. Создание проекта в Supabase
1. Перейдите на [supabase.com](https://supabase.com) и зарегистрируйтесь / войдите.
2. Нажмите **New Project**, укажите имя (например, `bk-pharmacy-db`) и надёжный пароль базы данных.

### Шаг 2. Создание таблиц и политик безопасности (SQL Schema)
1. В левой панели Supabase откройте раздел **SQL Editor**.
2. Откройте файл `supabase/schema.sql` из этого проекта, скопируйте его содержимое, вставьте в редактор Supabase и нажмите **Run**.
   - Будут созданы таблицы `categories`, `products`, `orders`, `site_settings`.
   - Будут настроены политики Row Level Security (RLS) для публичного чтения и защиты админ-доступа.
   - Будет создан публичный бакет хранилища `product-images`.

### Шаг 3. Загрузка стартовых товаров (Seed Data)
1. В **SQL Editor** создайте новый запрос.
2. Скопируйте содержимое файла `supabase/seed.sql` и нажмите **Run**.
   - В базу будут добавлены 16 стартовых препаратов, все категории и контакты директора.

### Шаг 4. Создание администратора
1. В Supabase перейдите в **Authentication** -> **Users**.
2. Нажмите **Add user** -> **Create user**.
3. Укажите Email (например, `admin@bk-pharmacy.uz`) и пароль.

### Шаг 5. Настройка переменных окружения
1. В Supabase перейдите в **Project Settings** -> **API**.
2. Скопируйте **Project URL** и **anon public key**.
3. В корне проекта переименуйте `.env.example` в `.env` и вставьте ваши ключи:
   ```env
   VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```
4. Перезапустите проект (`npm run dev`). Сайт автоматически переключится на работу с облачной базой Supabase!

## 🌐 Публикация (Деплой)

### Деплой на Vercel (Быстрый и удобный)

1. Загрузите проект в репозиторий на GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of BK Pharmacy"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/bk-pharmacy.git
   git push -u origin main
   ```
2. Откройте [vercel.com](https://vercel.com), войдите через GitHub и нажмите **Add New Project**.
3. Выберите репозиторий `bk-pharmacy`.
4. В поле **Environment Variables** добавьте:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. Нажмите **Deploy**. Через 1 минуту ваш сайт будет доступен во всём мире на бесплатном домене `.vercel.app`!

### Деплой на GitHub Pages

1. В файле `vite.config.js` добавьте базовый путь репозитория:
   ```javascript
   export default defineConfig({
     base: '/bk-pharmacy/',
     plugins: [react()],
   });
   ```
2. Соберите проект:
   ```bash
   npm run build
   ```
3. Опубликуйте содержимое папки `dist` в ветку `gh-pages`:
   ```bash
   npx gh-pages -d dist
   ```
